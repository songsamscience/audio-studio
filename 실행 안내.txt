송쌤과학 음원 변환 스튜디오

1. 이 폴더 전체를 그대로 보관하세요. vendor 폴더의 실행 자원이 필요합니다.
   특히 vendor\ffmpeg-core.wasm(약 32 MB)이 빠지면 변환이 되지 않습니다.
   첫 화면에 「변환 엔진 파일이 없습니다」가 보이면 이 파일을 다시 복사하세요.
2. Python 3가 설치된 컴퓨터에서 이 폴더를 터미널로 열고 다음을 실행하세요.

   python3 serve.py

   Windows에서는 python serve.py 또는 py serve.py를 사용할 수 있습니다.

3. 브라우저에서 http://127.0.0.1:8765 를 여세요.

HTML 파일을 더블클릭하면 화면은 열리지만 브라우저 보안 정책 때문에
변환 엔진은 실행되지 않습니다. 위 HTTP 실행 또는 정적 웹 호스팅이 필요합니다.
별도 설치 없이 정적 웹 호스팅에 올릴 때도 폴더 구조를 유지하세요.

사용 순서
파일 선택 → 구간 편집 → 형식·용량 선택 → 전후 듣기 → 변환 → 최종 듣기 → 다운로드
파일을 열면 영상인지 음원인지 확인해 맞는 메뉴(MP3로 · 영상에서 소리 꺼내기 · 다른 음원 형식으로 · 영상 만들기)가 나타납니다.
저장 형식: MP3 · M4A · AAC · M4R · OGG · Opus(모노) · WebM(모노) · WMA · MP2 · AC3 · WAV · FLAC · ALAC · AIFF · CAF · AU,
그리고 음원을 화면과 함께 담은 MP4 · WebM 영상(유튜브·수업 자료용).

파일은 서버에 업로드하지 않습니다. 처리와 분석은 브라우저 안에서 이루어집니다.
창을 닫기 전에 결과를 다운로드하세요. 작업 설정 JSON에는 원본 음원이 포함되지 않습니다.

자세한 기능·제약·배포 설명은 README.md를 참고하세요.
