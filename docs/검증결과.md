## v1.3.0 macOS 검증 (2026-10-05) — 파일당 4 GB

환경: macOS · Claude 앱 내장 브라우저(Chromium) · `serve.py`와 같은 처리기(CSP 포함)에 시험용 큰 파일 경로만 더한 로컬 서버. 큰 시험 파일은 OneDrive 밖 임시 폴더에 성긴 파일(sparse)로 만들어 실제 디스크는 거의 쓰지 않았습니다.

## v1.2.2 macOS 검증 (2026-10-05) — 오류 수정·기능 정리

환경: macOS · Claude 앱 내장 브라우저(Chromium) · `serve.py` 8765(CSP 포함) · 모델 테스트는 `python -m http.server 8852`.

### 점검 방법
1. **오류 탐색**: 코드 고정본을 6갈래(재생, 편집, 파일·녹음, 엔진, 출력·일괄, 화면·생명주기)로 나눠 검토자 6명이 찾고, 보고마다 다른 검토자가 반박을 시도했습니다. 64건 보고 → 59건 확인(5건 기각) → 겹침 정리 약 45건을 모두 고쳤습니다.
2. **쓸데없는 기능·외부 API 점검**: 네트워크 요청 전수 조사(외부 서비스 호출 0건 — 유튜브·인스타그램 링크만 사용자가 눌러 여는 외부 주소), 쓰이지 않는 코드·파일, 교사 입장의 중복 기능을 찾고 「남겨야 한다」는 반대 검증을 거친 22건 중 아래만 삭제했습니다. 원래 제작 요구서에 있던 기능(비슷한 음량 비교, 레벨 미터, 확인용 속도, 작업 설정 저장, 오프라인 준비, 보정 프리셋 등)은 남겼습니다.
3. **실제 화면 점검**: 사람이 누르듯 화면 단추를 눌러 결과 소리를 다시 디코딩해 길이·주파수·최고값을 쟀습니다.
